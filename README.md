**[InsightVox — Campus Feedback System](https://github.com/namrah-k/InsightVox-Campus-Feedback-System)**
Two-sided platform for campuses. Students post complaints with photo/video, vote on each other's posts, and message staff privately. Staff get a dashboard to track and resolve everything. Built with vanilla JS + Express + MongoDB.

**[Security Alert Fatigue Detection System](https://github.com/anushka2920/miniiproj)**
A Python + Flask desktop dashboard that monitors running applications in real time and detects when users start ignoring security warnings — a problem known as alert fatigue. The system calculates a threat score from suspicious process behavior (CPU spikes, memory surges, thread explosions) and a fatigue score from how the user responds to alerts (ignored, snoozed, acknowledged). When fatigue gets too high, low-priority alerts are suppressed automatically while critical ones stay visible. Users can trust, block, kill, snooze, or acknowledge any process directly from the dashboard. Built with Python, Flask, PyQt5, Scikit-learn (Isolation Forest), Pandas, and NumPy.
